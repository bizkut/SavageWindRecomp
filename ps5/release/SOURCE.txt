Savage Wind PS5 console-variant source information

Release @TAG@, source commit @COMMIT@

The release tree contains the title and storage-broker sources, vendored source,
patches and build scripts. The root LICENSE applies MIT terms to Savage Wind
Recomp's own upstream code; individual PS5 files identify GPL-3.0-or-later.
MihawkGen is GPL-3.0-or-later. The combined title is distributed under
GPL-3.0-or-later; see notices/MIHAWKGEN.txt for the full GPL text and
notices/THIRD_PARTY_NOTICES.txt for additional notices and limitations.
Game code and assets generated from the user's game are not included here.

Reproduction entry points (Linux host): ps5/tools/setup-deps.sh,
ps5/tools/build-llvm-ps5.sh, ps5/tools/build-capstone-ps5.sh, and
PS5_GAMECODE=console ps5/tools/build-game.sh. The latter invokes build-title.sh,
build-importer.sh, build-shaderc.sh, build-ncnn.sh, setup-hd-ui.sh and
setup-ffmpeg.sh and setup-fontlibs.sh. The broker is built by
ps5/storagebroker/Makefile. These scripts depend on separately supplied pinned
inputs; availability of source and recipes does not prove byte-for-byte provenance.

Source and decisions

FFmpeg and FreeType are built from pinned upstream sources by the in-repository
setup-ffmpeg.sh and setup-fontlibs.sh scripts, respectively. FreeType uses its
bundled zlib. The host compiler-rt package and its source are identified above.
The PS5 payload SDK runtime source and build workflow are public at upstream
commit 4eb701204fc3f8d31e84cf8ca272974e2be9c867 and the public fork commit
fdb2763789a50a4fcc9a98dcae13f5e336c6a1ee, as linked above.
RADV uses pinned Mesa f10c4bac9b71c45a4c794ecc3c227eb6f6a56361 and public
patches at bizkut/ps5-forever commit a5f0b29e31153afa13d6462481fb651cfaac650a;
notices/MESA.txt contains the licence catalogue, not all copyright notices.
Vendored components' source is in this repository under third_party/ at the
tagged commit. The maintainer's decision for the Real-ESRGAN weights is
recorded above. PS5 system modules are system libraries of the console OS and
are not distributed in this package.
